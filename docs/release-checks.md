# v0.1.0 交付检查

日期：2026-11-03。

- `npm run check`：TypeScript 类型检查、4 个测试文件 / 20 项测试、ESM / CJS / 类型声明、源码 registry 和静态演示站构建通过。
- `npm audit`：当前锁文件 0 个漏洞。
- `npm pack --dry-run`：包含 ESM / CJS、声明、CSS、默认字体及三份 OFL 许可证、README、MIT 和授权清单。
- 浏览器：开始、关卡、战斗和结算界面可访问；生产包放在子目录路径后能正常渲染。四个游戏界面的直接可见文字字号不小于 20px，字重均不低于 700。
- 生产预览发现并修复源码 barrel 被 tree shaking 后丢失组件样式的问题；演示入口显式引入基础、文字、可读性与动效样式。构建末尾检查产物中的导航、遮罩和星级动画样式，防止再次漏包。
- 动效开关：默认跟随系统，显式选择完整动效后可覆盖系统减少动效；顶部和动效预览页显示有效状态。自动化覆盖系统减少动效、完整开箱 2200ms、减少动效完成态、偏好持久化和运行中的系统设置变化。浏览器帧变化与线上部署需另行核对，不能只根据动画名称存在判定播放正常。
- 手机宽度：关卡奖励使用彩色金币 / 宝石插图；返回 / 设置使用一致的蓝色立体按钮与实心图标；地图增加纵向间距，8 个关卡的选中标签布局均在边界内，且与其他节点无重叠。
- 宝箱：四种品质配对的关闭 / 开启插图；待机、开箱、已开箱均有预览；扫光按透明轮廓居中等比裁切，并同步插图变换；开箱过程保留外放金光、爆闪与粒子。
- 结算：三个空星槽始终保留，黄色立体星星错峰砸入、压扁拉伸并回弹；真实战斗流程已验证胜利、奖励领取、关卡解锁和重复返回不重复发奖。
- 图片：17 张 UI WebP 均保留 alpha，原始 PNG、生成提示词和文件映射随源码保留。
- 商用：项目代码、原创 SVG 与选定生成插图采用 MIT，外部字体采用 SIL OFL 1.1；内部字体改名、来源和保留名称处理记录见授权清单。

验证范围包含 Windows 本地浏览器及 GitHub CI 中的构建与自动化测试。界面示例中的战斗用于演示组件交互，未做完整游戏平衡、联网或真机设备矩阵验收；源码 registry 的 shadcn CLI 消费安装需在目标项目验证。
