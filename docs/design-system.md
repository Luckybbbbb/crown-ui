# Crown UI v0.1 设计定义

2026-11-03。首版目标是欧式卡通游戏界面组件库，同时覆盖开始、选关、玩法、结算四个完整例子。风格方向来自用户指定的《皇室战争》气质；分发组织参考 Warcraft UI 和 Animal Island UI。

## 视觉语言

- 主色：皇家蓝 `#3aa6f5`，荣耀金 `#ffd45d`，草地绿 `#87cf4e`，珊瑚红 `#f27668`，圣水紫 `#c087f4`。
- 文档容器：羊皮纸 `#fffaf0`，正文深蓝灰 `#263c52`，细描边与浅色底座。
- 材质通过高光、主体、下沿三个层次表达；按钮有 4px 实体底座，按下位移 3px。
- 用户最终确认的文字方向：所有可见文字最小 20px；整体粗体、可爱风；游戏文字采用白字、黑色描边和正下方硬阴影。容器与排版随字号一起调整。
- 中文使用 Resource Han Rounded CN Heavy 的改名子集 Crown Rounded SC；英文展示与数字采用 Lilita One 衍生 Crown Latin Display；正文英文 Nunito 900，罕用中文回退 Noto Sans SC 900。全部字体保留 SIL OFL 1.1。
- 图标采用一致圆角线条，游戏卡牌通过边框、底色和图标区分稀有度。
- 组件不使用官方游戏 logo、人物或原始贴图。城堡为本项目生成的原创示例素材。

## 动效

| 场景 | 动效                                                             |
| ---- | ---------------------------------------------------------------- |
| 全局 | 按钮按压 140ms，面板入场，进度条 500ms，资源变化弹动             |
| 开始 | 城堡轻缓浮动，云层漂移，菜单 450–650ms 错峰入场                  |
| 选关 | 路径淡入，当前可挑战节点光晕，选中虚线环，详情滑入               |
| 玩法 | 卡牌抬升，部署弹入，单位行进，城堡受击，伤害飘字                 |
| 结算 | 标题弹入，星级每颗间隔 200ms，奖励数字 1000ms 增长，彩纸 3s 下落 |

同时支持系统 `prefers-reduced-motion` 和手动 `data-reduced-motion`。减少动效不会停止战斗计时或改变状态结果。

## 分层

1. `src` 仅包含主题组件和独立样式，不耦合浏览器存档、示例战斗或插画。
2. `demo/screens` 组合组件表达完整流程。战斗逻辑可被真实玩法替换。
3. 文档提供交互预览、代码、参数、设计规范以及本地组件包下载。
4. `registry` 是源码分发载体，npm tarball 是构建产物；两个渠道使用同一份源组件。

## 首版边界

此版本用于建立原创视觉与可复用组件模式。文档、构建、状态测试通过不能替代用户美术验收、真实手机触摸验收或下游项目兼容验收。完整商业游戏平衡、联网、账号存档不属于本次组件库示例。
