# 宝箱与星级动效

用户要求：宝箱待机、开箱过程和已开箱三个状态均有动态预览；开箱加入金光闪耀。结算保留三个空星底图，黄色星星有力量感地砸入，带变形与回弹。

## 宝箱

默认过程时长 2200ms。0–40% 蓄力、下压和渐强抖动；40–55% 锁缝金光、向上光束、爆闪、放射光和粒子爆发；45–75% 展开到同品质的已开箱图，并产生短促缩放回弹；后段进入浮动与余辉。

当前使用配对的透明 3D 插图、2D 变换、遮罩扫光和粒子特效组合表达开箱，不是可任意转动的实时 3D 模型或逐帧骨骼动画。原始关闭 / 开启图形和品质配对见 `art-manifest.json`。

待机持续呼吸、扫光和星点闪动；已开箱持续浮动、缓转金光、呼吸亮度和星点。动态预览页的开箱过程循环播放，真实操作一次播放后通过 `onOpenComplete` 进入已开箱状态。组件卸载和状态中断会清理计时器。

扫光遮罩与插图都使用居中等比例适配（`contain`），避免预览容器较宽时把遮罩拉伸成一片半透明闪光。待机扫光同步呼吸变换，已开箱扫光同步浮动变换；开箱过程的外放金光使用独立图层。

## 三星打击

使用专门生成的黄色立体星星与匹配的灰蓝空星槽。三个空星槽永远存在，获得的星星覆盖其上；未获得星星的底座保持空态。

- 错峰开始：350 / 800 / 1250ms。
- 单颗时长：760ms。
- 入场：从上方放大状态快速下落，轻微旋转。
- 接触：横向扩大到 125%，纵向压到 65%，随后反向拉伸至 85% / 118%。
- 回弹：上抛 13px，再进行两次逐渐衰减的变形，最终归位。
- 打击层：冲击光圈、短闪、六个金色碎屑、底槽压震和星级行的短促下震。

结算时间线：先完成三星打击；2200ms 开始宝箱过程；3200ms 随金光爆发开始奖励数字增长；4400ms 宝箱进入已开箱状态。重播按钮重置本地视觉状态，不重复发放奖励。

减少动效时直接呈现完成态，保留底图、状态切换和奖励逻辑。所有新增预览文字保持最小 20px 与粗体。
